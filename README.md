# MineGame RPG — As Minas de Eldor

Protótipo jogável de um RPG de navegador desenvolvido como demonstração de capacidade de desenvolvimento front-end.

## Recursos
- Combate por turnos
- Ataque físico e habilidade com mana
- Poções e inventário
- XP, níveis e progressão de atributos
- Ouro e recompensas
- Três regiões com dificuldade progressiva
- Diferentes inimigos
- Registro de combate
- Salvamento no navegador com LocalStorage
- Interface responsiva para celular
- Atalhos de teclado

## Como jogar
Abra o arquivo index.html em um navegador. Não é necessário servidor ou banco de dados.

Atalhos: 1 Ataque · 2 Golpe Arcano · 3 Poção · 4 Fugir · I Inventário

## Evolução
A estrutura foi preparada para receber equipamentos, árvore de habilidades, quests, NPCs, crafting, lojas, chefes, multiplayer e backend/API.

Projeto demonstrativo — não representa um cliente real.
